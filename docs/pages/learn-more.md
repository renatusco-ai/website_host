# Learn More

**Route:** `/learn-more`  
**Component:** `src/pages/WhyCustom.jsx`  
**Visuals:** `src/components/SoftwareStoryGraphic.jsx`

## Purpose

Explain why generic per-seat software became the default, why that default is
especially costly for distinctive businesses, and why modern custom software
can now create measurable savings.

## Entry and exit

- Entry: Home hero link, **Learn how businesses are making crazy savings**
- Primary exit: Enquire Now modal with `subscription` intent
- Proof exit: `/portfolio/lockeroom`

## Story chapters

1. Traditional software required large teams, long timelines, and major funding
2. High build cost forced products to serve the largest possible market
3. Distinctive businesses are where generic tools fit worst
4. Gap-filling tools plus per-seat pricing compound the bill
5. Duct-tape workflows, poor support, and trapped data add hidden cost
6. Modern development makes an owned central source of truth practical
7. Lockeroom proves the model with `$266,651` documented annual savings

## Motion

- A gold SVG path draws down the page from `useScroll()` progress
- Seven illustrated chapters reveal as the user follows the path
- Hero background elements move at opposing parallax speeds
- `prefers-reduced-motion` renders the path complete and disables the scroll cue
- Mobile moves the path to the left rail and stacks copy above each illustration
